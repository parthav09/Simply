# Current implementation

Python owns shopping actions, accounting, run records and outcome metrics.
React displays those records through live SSE and deterministic replay.
New runs use unique product targets, reject duplicate pickups, and complete
payment in one checkout action. Shopper budgets remain soft targets.
The run freezes `unique_single_checkout_v1`; the informed prompt describes
the same rules. Navigation assistance is versioned and its adjustments recorded.

## Retained evidence

The October 29 matrix retains eight canonical recordings: seven complete runs
and one run interrupted by exhausted OpenAI credits. It covers 80 attempted
simulated trips and 70 completed checkouts. Twelve planned runs were not
collected. The findings are exploratory, with only one or two complete paired
repetitions per contrast. Both separate pilots and the original historical A/B
demonstrations remain separate from main estimates. Their identities and source
bytes are unchanged. Older deleted archives were not restored.

The Evidence page leads with four model/layout conditions and explicitly shows
the interruption and missing collection. Individual runs, full study reports,
diagnostics and source downloads are collapsed. Unknown charges stay unknown;
the persistent ledger and reservations are preserved. A read-only matrix
verification command reconstructs exported results from original recordings.
Test fixtures remain software checks and never stand in for model evidence.
